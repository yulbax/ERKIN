# 规则和连接

规则会把匹配的连接发送到 Direct、ByeDPI、VPN 或 Block，与应用的通道无关。

## 规则

- 规则从上到下检查，第一条匹配的规则生效。拖动即可调整顺序。
- 规则可以匹配域名、域名后缀、关键词、IP 地址或子网、国家，或已下载的规则集。
- “应用”字段可以把规则限定为一个应用。不填时，规则作用于除 Bypass 以外的所有应用。
- VPN 规则可以有自己的服务器或代理链。
- “设置 → 网络”中的“阻止 QUIC”和“绕过局域网”先于规则生效。

## 规则集

“规则”顶栏中的下载按钮会打开“规则集”：广告和遥测列表、各国 IP 段，以及包含 YouTube、Telegram 和 Discord 现成规则集的“服务”分组。也可以通过链接添加自己的规则集。

## 连接

“连接”显示 ERKIN 连接期间各应用去了哪里：本次会话按通道统计的流量，以及应用及其访问的地址。只显示经过 ERKIN 的应用，也就是除 Bypass 以外的所有应用。

- 在应用中可以看到它打开过哪些地址、产生了多少流量，以及走的是哪个通道或规则。
- 地址旁的 ⋮ 菜单可仅为此应用创建针对该地址或整个网站的规则。“规则”标签页列出该应用的规则。
