# 通道

每个应用使用一个通道：

- **Direct** — 不经过隧道，与没有 ERKIN 时相同。
- **ByeDPI** — 经由设备上的 ByeDPI，无需服务器。
- **VPN** — 经由服务器。
- **Block** — ERKIN 连接期间无法访问网络。

![应用](../img/zh/apps.webp)

- 点按应用右侧的按钮选择通道。如果应用有自己的服务器，按钮上会显示服务器名称。
- 在菜单中，VPN 下方的“服务器”一行可为应用指定单独的服务器或链，代替主服务器。
- 列表上方的筛选显示每个通道中的应用数量，并可筛选列表。
- 要同时修改多个应用，请长按一个应用或点按搜索框中的选择按钮，勾选应用后选择通道或服务器。可以撤销。
- 新应用的通道在“设置 → 应用”中设置。ru、vk 和 yandex 应用默认使用 Direct。
- 规则优先于通道：匹配规则的连接按规则指定的方向走。VPN 规则也可以有自己的服务器。
- Block 优先于规则：被阻止的应用完全无法联网。
