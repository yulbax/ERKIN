# 故障排除

**ByeDPI：网站无法打开。** ByeDPI → “寻找策略”，然后应用结果最好的策略。如果无效，请在“设置 → 网络”中更换“ByeDPI DNS”或关闭其加密。

**VPN 无法使用。** 在主屏幕运行“测试延迟”，选择有响应的服务器。若是订阅，请刷新订阅。 如果订阅服务器在连接期间停止响应，ERKIN 会在三次重连后自动切换到最快的服务器。

**主屏幕显示“无响应”。** 下方一行说明哪个没有响应：VPN 服务器还是 ByeDPI。对于 ByeDPI，请在其页面寻找策略。

**应用没有走它的通道。** 检查“规则”：匹配的规则优先于应用的通道。 应用实际去了哪里，可以在“连接”中查看。

**规则对某个应用不生效。** Bypass 通道中的应用绕过 ERKIN。如果需要规则生效，请把它改为 Direct。

**银行应用发现了 VPN。** 把它改为 Bypass：这样它就在隧道之外运行。

**无法访问家庭网络中的设备。** 在“设置 → 网络”中开启“绕过局域网”。

**被阻止的应用仍然可以联网。** 阻止只在 ERKIN 连接期间生效。

**发送报告。** “日志” → “分享”。报告包含应用、内核和 ByeDPI 的日志。
