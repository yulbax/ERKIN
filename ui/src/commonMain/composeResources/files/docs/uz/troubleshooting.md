# Nosozliklar

**ByeDPI: «saytlar ochilmayapti».** ByeDPI → «Strategiya tanlash», soʻng eng yaxshi natijali strategiyani qoʻllang. Yordam bermasa, «Sozlamalar → Tarmoq»da «ByeDPI uchun DNS»ni oʻzgartiring yoki uning shifrlashini oʻchiring.

**VPN ishlamayapti.** Bosh ekranda — «Kechikishni tekshirish», soʻng javob berayotgan serverni tanlang. Obuna boʻlsa, uni yangilang. Obuna serveri ishlash vaqtida javob bermay qolsa, ERKIN uch marta qayta ulangandan soʻng oʻzi eng tez serverga oʻtadi.

**Bosh ekranda «Javob yoʻq».** Uning ostidagi yozuv nima javob bermayotganini aytadi: VPN-server yoki ByeDPI. ByeDPI uchun uning boʻlimida strategiya tanlang.

**Ilova oʻz kanali orqali ishlamayapti.** «Qoidalar»ni tekshiring: mos kelgan qoida ilova kanalidan ustun. Ilova aslida qayerga borayotganini «Ulanishlar»da koʻrish mumkin.

**Qoidalar ilovaga taʼsir qilmaydi.** Bypass kanalidagi ilova ERKIN’ni chetlab oʻtadi. Qoidalar unga taʼsir qilishi kerak boʻlsa, uni Direct’ga oʻtkazing.

**Bank ilovasi VPN’ni payqaydi.** Uni Bypass’ga oʻtkazing: shunda u tunneldan tashqarida ishlaydi.

**Uy tarmogʻidagi qurilmalar koʻrinmayapti.** «Sozlamalar → Tarmoq»da «Lokal tarmoqni chetlab oʻtish»ni yoqing.

**Bloklangan ilova baribir tarmoqqa chiqyapti.** Bloklash faqat ERKIN ulangan paytda ishlaydi.

**Hisobot yuborish.** «Jurnal» → «Ulashish». Hisobotga ilova, yadro va ByeDPI jurnallari kiradi.
