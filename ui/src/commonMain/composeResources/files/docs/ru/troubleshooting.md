# Неполадки

**ByeDPI: «сайты не открываются».** ByeDPI → «Подбор», затем примените стратегию с лучшим результатом. Если не помогает, смените «DNS для ByeDPI» в «Настройки → Сеть» или выключите для него шифрование.

**VPN не работает.** На главном экране — «Проверить задержку», затем выберите отвечающий сервер. Для подписки — обновите её. Если сервер подписки перестал отвечать во время работы, ERKIN после трёх переподключений сам переключится на самый быстрый.

**«Нет ответа» на главном экране.** Подпись под ним говорит, что не отвечает: VPN-сервер или ByeDPI. Для ByeDPI подберите стратегию в его разделе.

**Приложение идёт не через свой канал.** Проверьте «Правила»: совпавшее правило важнее канала приложения. Куда на самом деле ходит приложение, видно в «Соединениях».

**Правила не действуют на приложение.** Приложение в канале Bypass идёт мимо ERKIN. Переведите его в Direct, если на него должны действовать правила.

**Банковское приложение замечает VPN.** Переведите его в Bypass: тогда оно не видит VPN.

**Не видно устройств домашней сети.** Включите «Обход LAN» в «Настройки → Сеть».

**Заблокированное приложение всё равно работает с сетью.** Блокировка действует, только пока ERKIN подключён.

**Отправить отчёт.** «Логи» → «Поделиться». В отчёт попадают логи приложения, ядра и ByeDPI.
