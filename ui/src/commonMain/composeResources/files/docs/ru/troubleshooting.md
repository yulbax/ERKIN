# Неполадки

**ByeDPI: «сайты не открываются».** ByeDPI → «Подбор», затем примените стратегию с лучшим результатом. Если не помогает, смените «DNS для ByeDPI» в «Настройки → Сеть» или выключите для него шифрование.

**VPN не работает.** На главном экране — «Проверить задержку», затем выберите отвечающий сервер. Для подписки — обновите её.

**Приложение идёт не через свой канал.** Проверьте «Правила»: совпавшее правило важнее канала приложения.

**Не видно устройств домашней сети.** Включите «Обход LAN» в «Настройки → Сеть».

**Отправить отчёт.** «Логи» → «Поделиться». В отчёт попадают логи приложения, ядра и ByeDPI.
