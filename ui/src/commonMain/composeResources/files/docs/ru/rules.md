# Правила и соединения

Правило отправляет совпавшие соединения в Direct, ByeDPI, VPN или Block, независимо от канала приложения.

## Правила

- Правила проверяются сверху вниз, срабатывает первое подходящее. Порядок меняется перетаскиванием.
- Правило может проверять домен, суффикс домена, ключевое слово, IP-адрес или подсеть, страну или скачанный набор правил.
- В поле «Приложение» правило можно ограничить одним приложением. Без него правило действует на все приложения, кроме Bypass.
- У правила с VPN может быть свой сервер или цепочка.
- «Блокировать QUIC» и «Обход LAN» из «Настройки → Сеть» срабатывают раньше правил.

## Наборы правил

Кнопка загрузки в шапке «Правил» открывает «Наборы правил»: списки рекламы и телеметрии, IP-адреса стран и группу «Сервисы» с готовыми наборами для YouTube, Telegram и Discord. Свой набор можно добавить по ссылке.

## Соединения

Раздел «Соединения» показывает, куда ходят приложения, пока ERKIN подключён: трафик за сеанс по каналам и список приложений с адресами. Видны только приложения, которые идут через ERKIN, то есть все, кроме Bypass.

- В приложении видно, какие адреса оно открывало, сколько трафика ушло и по какому каналу или правилу.
- Меню ⋮ у адреса создаёт правило для этого адреса или всего сайта только для этого приложения. На вкладке «Правила» — правила приложения.
