# Каналы

Каждое приложение идёт через один из каналов:

- **Direct** — мимо туннеля, как без ERKIN.
- **ByeDPI** — через ByeDPI на устройстве, сервер не нужен.
- **VPN** — через сервер.
- **Block** — без доступа к сети, пока ERKIN подключён.

![Приложения](../img/ru/apps.webp)

- Канал выбирается кнопкой справа от приложения. Если у приложения свой сервер, на кнопке написано его название.
- В меню под VPN строка «Сервер» задаёт приложению свой сервер или цепочку вместо основного.
- Фильтры над списком показывают, сколько приложений в каждом канале, и отбирают их.
- Чтобы изменить сразу несколько приложений, удерживайте приложение или нажмите кнопку выбора в поле поиска, отметьте приложения и выберите канал или сервер. Действие можно отменить.
- Канал для новых приложений задаётся в «Настройки → Приложения». Приложения ru, vk и yandex начинают с Direct.
- Правила важнее канала: если соединение совпало с правилом, оно идёт туда, куда указывает правило. У VPN-правила тоже может быть свой сервер.
- Block важнее правил: заблокированное приложение не получает сеть совсем.
