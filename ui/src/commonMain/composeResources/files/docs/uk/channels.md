# Канали

Кожен застосунок іде через один із каналів:

- **Bypass** — повз ERKIN, як без нього. Застосунок поза тунелем, правила на нього не діють. Є лише на Android.
- **Direct** — через ERKIN напряму, без сервера. Правила працюють, застосунок видно в «З’єднаннях», але він бачить VPN.
- **ByeDPI** — через ByeDPI на пристрої, сервер не потрібен.
- **VPN** — через сервер.
- **Block** — без доступу до мережі, доки ERKIN підключено.

![Застосунки](../img/uk/apps.webp)

- Канал вибирається кнопкою праворуч від застосунку. Якщо в застосунку свій сервер, на кнопці написано його назву.
- У меню під VPN рядок «Сервер» задає застосунку свій сервер або ланцюжок замість основного.
- Фільтри над списком показують, скільки застосунків у кожному каналі, і відбирають їх. Після каналів ідуть сервери й ланцюжки, до яких прив’язані застосунки.
- Щоб змінити кілька застосунків одразу, утримуйте застосунок або натисніть кнопку вибору в полі пошуку, позначте застосунки й виберіть канал або сервер. Дію можна скасувати.
- Канал для нових застосунків задається в «Налаштування → Застосунки». Застосунки ru, vk і yandex починають із Bypass.
- Правила важливіші за канал: якщо з’єднання збіглося з правилом, воно йде туди, куди вказує правило. Докладніше — у статті «Правила і з’єднання».
- Block важливіший за загальні правила: заблокованому застосунку мережу відкривають лише його власні правила.

## Ланцюжки

У розділі «Ланцюжки» можна зібрати шлях із кількох серверів: вхід, проміжні ланки й сервер виходу. Першою ланкою може бути ByeDPI. Ланки переставляються перетягуванням за ручку. Ланцюжок можна вибрати основним сервером або сервером застосунку, а «Перевірити затримку» вимірює його цілком.
