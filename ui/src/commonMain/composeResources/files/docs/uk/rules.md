# Правила і з’єднання

Правило спрямовує з’єднання, що збіглися, у Direct, ByeDPI, VPN або Block, незалежно від каналу застосунку.

## Правила

- Правила перевіряються згори донизу, спрацьовує перше відповідне. Порядок змінюється перетягуванням.
- Правило може перевіряти домен, суфікс домену, ключове слово, IP-адресу чи підмережу, країну або завантажений набір правил.
- У полі «Застосунок» правило можна обмежити одним застосунком. Без нього правило діє на всі застосунки, крім Bypass.
- У правила з VPN може бути свій сервер або ланцюжок.
- «Блокувати QUIC» і «Обхід LAN» з «Налаштування → Мережа» спрацьовують раніше за правила.

## Набори правил

Кнопка завантаження в шапці «Правил» відкриває «Набори правил»: списки реклами й телеметрії, IP-адреси країн і групу «Сервіси» з готовими наборами для YouTube, Telegram і Discord. Свій набір можна додати за посиланням.

## З’єднання

Розділ «З’єднання» показує, куди ходять застосунки, доки ERKIN підключено: трафік за сеанс за каналами і список застосунків з адресами. Видно лише застосунки, що йдуть через ERKIN, тобто всі, крім Bypass.

- У застосунку видно, які адреси він відкривав, скільки трафіку пішло і яким каналом чи правилом.
- Меню ⋮ біля адреси створює правило для цієї адреси або всього сайту лише для цього застосунку. На вкладці «Правила» — правила застосунку.
