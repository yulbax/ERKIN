# Неполадки

**ByeDPI: «сайти не відкриваються».** ByeDPI → «Підбір», потім застосуйте стратегію з найкращим результатом. Якщо не допомагає, змініть «DNS для ByeDPI» в «Налаштування → Мережа» або вимкніть для нього шифрування.

**VPN не працює.** На головному екрані — «Перевірити затримку», потім виберіть сервер, що відповідає. Для підписки — оновіть її. Якщо сервер підписки перестав відповідати під час роботи, ERKIN після трьох перепідключень сам перемкнеться на найшвидший.

**«Немає відповіді» на головному екрані.** Підпис під ним каже, що не відповідає: VPN-сервер чи ByeDPI. Для ByeDPI підберіть стратегію в його розділі.

**Застосунок іде не через свій канал.** Перевірте «Правила»: правило, що збіглося, важливіше за канал застосунку. Куди насправді ходить застосунок, видно в «З’єднаннях».

**Правила не діють на застосунок.** Застосунок у каналі Bypass іде повз ERKIN. Переведіть його в Direct, якщо на нього мають діяти правила.

**Банківський застосунок помічає VPN.** Переведіть його в Bypass: тоді він не бачить VPN.

**Не видно пристроїв домашньої мережі.** Увімкніть «Обхід LAN» в «Налаштування → Мережа».

**Заблокований застосунок усе одно має мережу.** Блокування діє, лише доки ERKIN підключено.

**Надіслати звіт.** «Журнал» → «Поділитися». У звіт потрапляють журнали застосунку, ядра й ByeDPI.
