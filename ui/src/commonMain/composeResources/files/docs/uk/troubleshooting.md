# Неполадки

**ByeDPI: «сайти не відкриваються».** ByeDPI → «Підбір», потім застосуйте стратегію з найкращим результатом. Якщо не допомагає, змініть «DNS для ByeDPI» в «Налаштування → Мережа» або вимкніть для нього шифрування.

**VPN не працює.** На головному екрані — «Перевірити затримку», потім виберіть сервер, що відповідає. Для підписки — оновіть її.

**Застосунок іде не через свій канал.** Перевірте «Правила»: правило, що збіглося, важливіше за канал застосунку.

**Не видно пристроїв домашньої мережі.** Увімкніть «Обхід LAN» в «Налаштування → Мережа».

**Пауза.** У сповіщенні є кнопка «Пауза»: ERKIN зупиняє тунель, і застосунки виходять у мережу напряму, без VPN, ByeDPI, правил і блокування. «Відновити» підключає знову.

**Заблокований застосунок усе одно має мережу.** Блокування діє, лише доки ERKIN підключено, а не на паузі й не після відключення.

**Надіслати звіт.** «Журнал» → «Поділитися». У звіт потрапляють журнали застосунку, ядра й ByeDPI.
