## Windows and Linux

- **ByeDPI now works properly.** Previously ByeDPI's traffic went through the sing-box tunnel, which reassembled the split packets, so DPI bypass barely worked. ByeDPI connections now go around the tunnel, straight through the network adapter, and the bypass tricks reach the network intact.
  - Windows: ByeDPI (`ciadpi.exe`) is built from byedpi 0.17.3 sources with a small patch that binds it to the network adapter.
  - Linux: uses byedpi's built-in support; the update installs as usual, no setup needed.
- **App list:** scrollbar with letters. Dragging the thumb shows the current letter; on release the list snaps to the start of that letter.
- **Side menu** no longer opens on an accidental swipe, only with the menu button.
- **Linux:** no more empty space for icons in the app list.

## Android

- **App list:** scrollbar with letters, same as on desktop. Shows up while scrolling.
