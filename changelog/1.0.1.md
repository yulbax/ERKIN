## Windows и Linux

- **ByeDPI работает корректно.** Раньше трафик ByeDPI попадал в туннель sing-box: тот собирал нарезанные пакеты обратно, и обход DPI почти не срабатывал. Теперь соединения ByeDPI идут мимо туннеля, напрямую через сетевой адаптер, и приёмы обхода доходят до сети без изменений.
  - Windows: ByeDPI (`ciadpi.exe`) собирается из исходников byedpi 0.17.3 с небольшим патчем для привязки к сетевому адаптеру.
  - Linux: используется штатная возможность byedpi, обновление ставится как обычно, без настроек.
- **Список приложений:** полоса прокрутки с буквами. При перетаскивании ползунка показывается буква, после отпускания список доводится к началу этой буквы.
- **Боковое меню** больше не открывается случайным свайпом, только кнопкой.
- **Linux:** в списке приложений больше нет пустого места под иконки.

## Android

- **Список приложений:** полоса прокрутки с буквами, как на ПК. Появляется во время прокрутки.
